# FeedDeck 前端设计提示词

将以下内容发送给 Google Stitch 生成前端界面设计。

---

## 项目名称
FeedDeck — iPad 信息流副屏仪表板

## 产品定位
一个部署在 Cloudflare 上的个人信息流仪表板，运行在 iPad mini（768x1024 竖屏）的 Safari 浏览器中，作为电脑旁边的副屏常亮显示。用户打开页面输入密码后，即可看到实时更新的新闻、热搜、天气、待办等信息。这是一个工具型产品，不是营销页面。

## 设计尺寸
768 x 1024 px（iPad mini 竖屏）

## 视觉风格
- **深色模式**为默认主题（深灰/近黑背景 #0f1117，卡片背景 #1a1d27，文字 #e4e4e7）
- 信息密度高但不拥挤，适合快速扫视
- 工具感、仪表盘感，安静低调，不花哨
- 每个功能模块是一个卡片（card），卡片之间有 12px 间距
- 卡片圆角 8px，内部 padding 16px
- 无装饰性渐变、光效、阴影，保持界面干净
- 字体使用系统字体栈（-apple-system, BlinkMacSystemFont, "SF Pro Text", "Helvetica Neue", sans-serif）
- 不使用 emoji 作为功能图标，使用简洁的线性图标（lucide 风格）

## 需要设计的页面

### 页面 1：登录页
- 居中显示一个简洁的密码输入框 + 登录按钮
- 背景与主仪表板一致（深色）
- 页面标题 "FeedDeck"，小号灰色副标题 "信息流仪表板"
- 输入框宽度适中（约 320px），圆角，深色背景
- 登录按钮为实心按钮，hover 时有轻微亮度变化
- 输入错误时输入框下方显示红色提示文字

### 页面 2：主仪表板
这是核心页面，需要最详细的设计。

**顶部固定栏（高度 56px）：**
- 左侧：当前时间（大号字体，如 "14:32"）+ 日期（小号灰色，如 "2026年6月7日 周六"）
- 右侧：天气小摘要（天气图标 + 温度，如 ☀ 28°）+ 刷新状态指示（小圆点，绿色=正常，黄色=数据较旧）+ 设置图标按钮（齿轮，点击跳转 /c 配置页）

**主体区域：** 2 列网格布局（每列宽约 372px），卡片按以下顺序排列：

**第 1 行（左列）：热搜榜卡片**
- 卡片标题栏：左侧 "🔥 热搜" 文字 + 右侧平台 tab 切换（如：微博 | 知乎 | 抖音 | B站，可横向滚动）
- 内容区域：排名列表，每行显示 排名序号（灰色小号）+ 标题文字 + 右侧热度值（灰色小号）
- 列表最多显示 15 行，超出时卡片内部可滚动
- 序号 1-3 用橙色/红色高亮

**第 1 行（右列）：新闻/RSS 卡片**
- 卡片标题栏：左侧 "📰 新闻" 文字 + 右侧筛选下拉（按来源筛选）
- 内容区域：新闻列表，每条显示 来源标签（小圆角标签，不同来源不同颜色）+ 标题（主文字）+ 下方灰色小字摘要截断（1行）+ 最右侧灰色小字时间（如 "5分钟前"）
- 列表最多显示 10 条，超出时卡片内部可滚动

**第 2 行（左列）：待办卡片**
- 卡片标题栏：左侧 "✅ 待办" 文字 + 右侧 "+" 添加按钮
- 内容区域：待办列表，每行显示 勾选框 + 标题文字 + 右侧截止时间（如有，灰色小字）
- 已完成项有删除线，灰色显示
- 已过期未完成的截止时间用红色显示
- 空状态显示 "暂无待办" 灰色提示文字

**第 2 行（右列）：日历卡片（v2）**
- 卡片标题栏：左侧 "📅 日程" 文字 + 右侧 "今天" 快捷按钮
- 内容区域：按日期分组的日程列表
- 每个日期一个小标题（如 "今天 6月7日"），下方列出该天的事件
- 每个事件显示：时间（如 "14:00-15:00"）+ 标题 + 来源标签（手动/订阅，不同颜色）
- 最多显示未来 7 天，超出时卡片内部可滚动
- 即将到来（1 小时内）的事件左侧有蓝色竖条高亮

**第 3 行（左列）：社交媒体卡片（v2）**
- 卡片标题栏：左侧 "👥 粉丝" 文字
- 内容区域：每个账号一行，显示 平台图标 + 账号名 + 右侧粉丝数（大号数字）
- 如果粉丝数有变化，显示变化量（+12 绿色 / -3 红色）

**第 3 行（右列）：天气卡片**
- 卡片标题栏：左侧 "🌤 天气" 文字 + 右侧城市名
- 内容区域：
  - 上半部分：当前天气大图标 + 温度（大号）+ 天气描述文字
  - 下半部分：未来几小时的逐时预报，横向排列小图标 + 温度
  - 底部：今日高/低温

### 页面 3：配置页（/c）
**布局：** 左侧导航栏（约 200px 宽）+ 右侧配置表单区

**左侧导航项：**
- 基本设置（密码修改、天气城市）
- RSS 订阅管理
- 热搜平台
- 社交媒体账号
- 日历/ICS 订阅
- 关于

**右侧表单区域示例（RSS 管理）：**
- 顶部：标题 "RSS 订阅管理" + "添加源" 按钮
- 列表：每个 RSS 源一行，显示 名称 + URL（灰色截断）+ 右侧编辑/删除按钮
- 添加/编辑时弹出 modal：输入名称 + RSS URL + 颜色标签选择

**配置页整体风格：**
- 深色背景与主仪表板一致
- 表单输入框：深色背景、浅色边框、圆角
- 按钮：实心主按钮（添加/保存）+ 文字按钮（删除/取消）
- 所有操作有确认提示（删除操作）

## 交互要求
- 所有卡片内容超出时内部滚动，不影响页面整体布局
- 勾选待办项时有平滑的删除线动画
- 页面切换（仪表板 ↔ 配置页）无白屏，直接跳转
- 点击新闻/热搜标题在新标签页打开原文
- 所有列表有 loading 状态（骨架屏或 spinner）
- 刷新状态指示实时反映数据新鲜度

## 不要做的事
- 不要做成 landing page / 营销页面风格
- 不要用大号 hero 区域
- 不要用渐变背景、光效、装饰性 blob
- 不要用 emoji 作为功能图标（可用作卡片标题前的装饰）
- 不要做成卡片居中、大量留白的"苹果风格"
- 不要加动画过渡特效（保持简单）
- 不要用圆角超过 8px 的元素

## 输出要求
- 输出 iPad mini 竖屏（768x1024）尺寸的设计稿
- 深色主题为主
- 需要输出：登录页、主仪表板、配置页 三个页面
- 主仪表板是最重要的页面，请重点设计
